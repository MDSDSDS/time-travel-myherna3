In this assignment I learned how to create and push files to a github repository remotely from the terminal. I also learned how to create and merge branches using pull requests. I ran into a mistake where I was editing the incorrect branch and caused a problem on the main branch, I used push --force origin main to fix this and ressolve the conflict. Another mistake I made was not adding my changes before commiting and seeing nothing committed, which confused me at first. The command that saved me was git status, being able to see what changes are staged and what changes need to still be added.
